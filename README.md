# Business Cards Manager — free-model version

A business-card management app for an office: add contacts from pasted text or a photo, review them, and find anyone by typing or by asking a question in English or Arabic.

This is the same app as the Business Cards Manager, with the AI provided by a **free model through the OpenRouter API** instead of a paid one.

**Status: planning.** This repository holds the plan only. No code has been written yet.
